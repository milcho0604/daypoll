## 첫 번째 내용

목차를 접고 펼치는 동작과 키보드 접근성을 확인합니다.

### 코드 예제

```ts
const verified = true;
console.log(verified);
```

스크롤 진행률을 검증할 수 있도록 충분한 본문을 둡니다. 같은 문장을 반복하는 대신 실제 읽기 화면의 여러 문단을 가정합니다.

본문의 폭이 작은 모바일 화면을 벗어나지 않아야 합니다. 긴 코드 블록은 본문 전체가 아니라 코드 영역 안에서만 가로로 스크롤되어야 합니다.

## 두 번째 내용

현재 읽는 목차 항목은 스크롤 위치에 맞춰 강조됩니다.

접근 가능한 이름이 있는 버튼과 링크를 사용하고, 복사 결과는 보조 기술에도 전달합니다.

사용자가 페이지 아래로 내려가면 맨 위로 이동할 수 있는 버튼이 나타납니다.

분석 이벤트에는 글 식별자와 정해진 행동만 포함하며 검색어 원문이나 개인 정보는 포함하지 않습니다.

### 마무리 점검

마지막 구간까지 읽으면 읽기 깊이 이벤트가 한 번만 기록됩니다.

레이아웃은 밝은 화면과 어두운 화면 모두에서 동일한 정보 구조를 유지합니다.
