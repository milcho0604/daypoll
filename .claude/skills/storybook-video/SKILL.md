# 동화책 스타일 영상 만들기 (storybook-video)

"푸들의 탄생 신화"(2026-09-26 제작, 60초·9:16)를 만든 절차를 그대로 재현하는 스킬.
**외부 API 호출 0번** — 그림은 SVG 코드로 직접 그리고, 음악은 파이썬 표준 라이브러리로 합성한다.

결과물 예시: `example/poodle-myth/contact-sheet.jpg` (먼저 열어서 톤을 확인할 것)

---

## 0. 요청을 받으면 먼저 정할 것

사용자가 따로 말하지 않으면 아래 기본값으로 바로 진행한다 (되묻지 말 것).

| 항목 | 기본값 |
|---|---|
| 길이 | 60초 (장면 8개 × 약 7초) |
| 비율 | 세로 9:16, 1080×1920, 30fps |
| 소리 | 자막 + 합성 BGM + 효과음 (내레이션 없음) |
| 톤 | 따뜻한 동화책 "옛날 옛적…" 존댓말 구어체 ("~했대요", "~였죠") |
| 사실성 | 실제 역사/사실 기반. 전설·통설은 "전해지길", "~라는 설도" 로 표시. 지어낸 사실 금지 |
| 저장 위치 | 스크래치패드(또는 사용자가 지정한 곳)에 `<slug>/` 폴더. **레포에 커밋하지 않는다** (요청 시에만) |

## 1. 준비 (도구)

```bash
# libx264 ffmpeg 확보 + playwright/python 확인. 마지막 줄이 export 문.
eval "$(bash .claude/skills/storybook-video/setup.sh | tail -1)"
# 예제 폴더를 새 프로젝트로 복사해서 시작
cp -r .claude/skills/storybook-video/example/poodle-myth <작업폴더>/<slug>
```

- Pretendard 폰트는 `render.mjs` 첫 실행 때 npm 에서 자동으로 받아 `fonts/` 에 둔다.
- 클라우드 세션: Playwright·Chromium 은 전역 설치돼 있음. 맥: `brew install ffmpeg` + `npm i -g playwright && npx playwright install chromium`.

## 2. 절차 (반드시 이 순서)

### ① 리서치 & 대본 (8장면)
- 이야기 구조: **인트로(옛날 옛적) → 기원 → 전성기/특징 2~3장면 → 오늘날 → 엔딩(한 줄 메시지)**.
  푸들 예: 인트로 → 늑대의 시대 → 물의 사냥개 → 푸들 컷의 비밀 → 프랑스의 사랑 → 재주꾼 → 오늘의 푸들 → 엔딩.
- 장면당 자막 2줄 × 2개 (각 약 3초). 한 줄은 **한국어 16자 안팎** (58px 에서 넘치지 않게).
- 사실 확인이 애매하면 톤으로 처리하고 최종 보고에 "사실 관계 메모"로 남긴다.
  (예: 푸들은 이름·기원은 독일 물사냥개설이 널리 퍼져 있지만 FCI 공식 원산지는 프랑스.)

### ② 스타일 가이드부터 (그림 그리기 전에)
`story.html` 상단 주석의 `STYLE GUIDE` 블록과 `const C = {...}` 팔레트를 새 주제에 맞게 정한다.
- 종이 배경 크림색 + 종이 결 노이즈 + 비네트 + 이중 책 테두리 (오버레이는 그대로 재사용)
- 따뜻한 팔레트 6색 + 주인공 전용 2색 (기본 + 그늘)
- 외곽선 6px 잉크색, `stroke-linejoin: round`. 세부 3~4px
- **주인공은 함수 하나로만 그린다** (`poodle(variant, opts)` 처럼) — 모든 장면에서 똑같이 보이는 게 퀄리티의 핵심

### ③ 장면 작성
각 장면은 `scene({...})` 한 번 호출. 자세한 API 는 `ENGINE.md`.
- 레이어 3단: 원경 `L(0.3~0.6, ...)` / 중경 `L(1, ...)` / 전경 `L(1.4~1.8, ...)` → 카메라 팬 시 패럴랙스
- 모든 장면에 켄 번즈: `zoom: [1, 1.06~1.1]`, `pan` 또는 `panFn`
- 가만히 있는 장면 금지 — idle 모션을 최소 2개: `data-anim="wag|bob|twinkle|flicker|ripple|fall|rise"` (꼬리, 불꽃, 물결, 꽃잎, 하트, 별)
- 장면 고유 연출(가위가 지나가며 털 정리, 라벨 등장 등)은 `SCENE_FX[id](tl, t, s)` 에
- 전환: `fade` (기본) / `iris` (원형, 인트로→본편·엔딩) / `wipe` (페이지 넘김) — 한 영상에 2~3종 섞기
- 챕터 라벨: `chap: ['첫 번째 이야기', '늑대의 시대']`

### ④ 음악
`bgm.py` 를 새 이야기에 맞게 수정. 푸들 예: 84 BPM, 뮤직박스 + 패드.
- 장면 분위기별로 조성 바꾸기 (신비=단조, 현재=한 톤 밝게, 엔딩=종지 F–G–C)
- 효과음은 **story.html 타임라인과 같은 시각**으로 (전환 휙, 첨벙, 가위, 반짝, 차임)
- 마지막 2~3초 페이드아웃

### ⑤ 검수 — 생략 금지 (최소 1회 수정 반복)
```bash
bash .claude/skills/storybook-video/sheet.sh <프로젝트> a 3,10,18,25,33,40,48,56,59,59.9
bash .claude/skills/storybook-video/sheet.sh <프로젝트> trans 6.7,14.2,21.7,29.2,36.7,44.2,52.2,1,2,58
```
→ 생성된 `sheet-*.png` 를 **Read 로 직접 보고** 아래 체크리스트로 확인·수정·재확인.

| 체크 | 푸들 때 실제로 걸렸던 것 |
|---|---|
| 캐릭터·소품이 화면 밖으로 잘림 | 늑대·아이가 가장자리에서 잘림 |
| 부자연스러운 그림 | 풀이 왕관 모양, 쓰다듬는 손이 머리 위에 떠 있음 |
| 경계선이 딱딱한 발광 | glow 는 반드시 radialGradient 로 부드럽게 |
| 배경 띠/줄무늬 아티팩트 | 밤하늘 그라데이션에 띠 |
| 빈 화면이 너무 김 | 엔딩 iris 시작 전 공백 |
| 요소 겹침 | 반짝이가 엔딩 글자 위에 |
| 가리키는 대상 어긋남 | 라벨 지시선 위치 |
| 소품 크기 | 가위가 너무 작음 |
| 자막 넘침·잘림, 이모지 네모(tofu) | — (이모지 대신 SVG 로 그릴 것) |

### ⑥ 렌더 & 확인
```bash
cd <프로젝트> && OUT=$PWD/<slug>.mp4 node render.mjs     # 60초 ≈ 5분
"$FFMPEG" -hide_banner -i <slug>.mp4 2>&1 | grep -E "Duration|Stream"   # 60s, 1080x1920, h264+aac 확인
```
최종 mp4 에서 컨택트시트를 한 번 더 뽑아 확인한 뒤 `SendUserFile` 로 전달한다.

### ⑦ 보고 형식
장면 표(시간·장면·전환·화면 내용) / 음악 요약 / 검수에서 고친 것 / 남은 약점 / 사실 관계 메모 / 재렌더 방법.

## 3. 알려진 약점과 다음에 개선할 점 (푸들 v1 기준)

- **크로스페이드 중간에 주인공이 두 마리 겹쳐 보임** → 같은 주인공이 연속 등장하는 전환은 `wipe`/`iris` 를 쓰거나, 종이색으로 잠깐 디졸브(dip-to-paper)하도록 개선.
- 늑대·손 같은 보조 캐릭터가 뻣뻣함 → 보조 캐릭터도 함수로 만들고 관절 하나(목/꼬리)라도 움직이기.
- 장면 하단이 비는 경우 → 전경 레이어(풀·꽃·소품)로 채우기.
- 파일 크기 20MB (CRF 20) → 전송용은 `-crf 23` 이면 절반 정도.
- 음악이 사인파 기반이라 단조로움 → 악기 음색(하모닉스·디튠) 추가 여지.

## 4. 이 스킬의 범위 밖

- 실사/3D 그림, AI 영상 클립 → 이미지/영상 생성 모델이 필요 (로컬 FLUX, 유료 Veo 등). 이 스킬은 코드로 그리는 일러스트 전용.
- 모일까(daypoll) 웹 UI 의 zinc/amber 디자인 토큰(CLAUDE.md)은 **이 영상에는 적용하지 않는다** — 영상은 위 ② 스타일 가이드를 따른다.

## 5. 파일 구성

```
.claude/skills/storybook-video/
├── SKILL.md          ← 이 문서 (절차)
├── ENGINE.md         ← story.html 엔진 API 레퍼런스
├── setup.sh          ← ffmpeg(libx264)/playwright 준비
├── sheet.sh          ← 검수용 컨택트시트
└── example/poodle-myth/
    ├── story.html    ← 푸들 60초 전체 (스타일·캐릭터·8장면·자막·전환)
    ├── render.mjs    ← seek(t) 프레임 캡처 → ffmpeg, BGM mux
    ├── bgm.py        ← 표준 라이브러리 음악·효과음 합성
    └── contact-sheet.jpg
```
